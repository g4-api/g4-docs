# G4.WebDriver.Remote.MacOs

## Description

`G4.WebDriver.Remote.MacOs` is the package for macOS automation through an Appium server. At the time of writing the project contains only its project file and references `G4.WebDriver.Remote.Appium`, so it adds no macOS-specific types of its own.

## Installation

```bash
dotnet add package G4.WebDriver.Remote.MacOs
```

You also need a running Appium server. Use the types from `G4.WebDriver.Remote.Appium` for now.

## Getting started (C# example)

```csharp
using G4.WebDriver.Remote.Appium;

// TODO(verify): no macOS-specific driver class exists in this package yet.
// AppiumDriverBase, AppiumOptionsBase and AppiumWebDriverServiceBase come from the Appium package.
```
