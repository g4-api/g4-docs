# G4.WebDriver.Remote.Firefox

## Description

`G4.WebDriver.Remote.Firefox` provides `FirefoxDriver`, `FirefoxOptions` and `FirefoxWebDriverService` for driving Mozilla Firefox through `geckodriver`.

## Installation

```bash
dotnet add package G4.WebDriver.Remote.Firefox
```

You also need `geckodriver`, or the address of a running WebDriver endpoint.

## Getting started (C# example)

```csharp
using G4.WebDriver.Models;
using G4.WebDriver.Remote;
using G4.WebDriver.Remote.Firefox;

// Create the driver with Firefox capabilities (starts geckodriver)
var options = new FirefoxOptions();
options.AddCapabilities("moz:firefoxOptions", new Dictionary<string, object>
{
    ["args"] = new[] { "-headless" }
});

using var driver = new FirefoxDriver(options);

// Navigate and read an element
driver.Navigate().Open("https://example.com");
var heading = driver.FindElement(By.CssSelector("h1"));
Console.WriteLine(heading.Text);

driver.Quit();

// Connect to an already running geckodriver instead
// using var remote = new FirefoxDriver(new Uri("http://localhost:4444"), options);
```
