# G4.WebDriver.Remote.Uia

## Description

`G4.WebDriver.Remote.Uia` provides `UiaDriver`, `UiaOptions` and `UiaWebDriverService` for driving Windows desktop applications through the G4 UIA WebDriver server. `UiaDriver` also implements `IUser32Driver` for user32-level input. `UiaOptions` sets the `app` and `arguments` of the application to start, and optional impersonation.

## Installation

```bash
dotnet add package G4.WebDriver.Remote.Uia
```

You also need the UIA WebDriver server running (see the `uia-driver-server` repository). Its README shows it listening on port 5555.

## Getting started (C# example)

```csharp
using G4.WebDriver.Models;
using G4.WebDriver.Remote;
using G4.WebDriver.Remote.Uia;

// Describe the application to start
var options = new UiaOptions
{
    App = @"C:\Windows\System32\notepad.exe"
};

// Connect to the UIA WebDriver server
using var driver = new UiaDriver(new Uri("http://localhost:5555/wd/hub"), options);

// Find an element and read its text
var element = driver.FindElement(By.Xpath("//Edit"));
Console.WriteLine(element.Text);

driver.Quit();
```
