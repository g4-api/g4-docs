# G4.WebDriver.Remote.Ios

## Description

`G4.WebDriver.Remote.Ios` provides `IosDriver` and `IosOptions` for iOS devices through an Appium server. Both are thin classes over the Appium base in `G4.WebDriver.Remote.Appium`.

## Installation

```bash
dotnet add package G4.WebDriver.Remote.Ios
```

You also need a running Appium server. `IosDriver` has a single constructor that takes a command invoker and a session model, so you build both yourself.

## Getting started (C# example)

```csharp
using G4.WebDriver.Extensions;
using G4.WebDriver.Remote;
using G4.WebDriver.Remote.Ios;

var options = new IosOptions();
options.AddCapabilities("platformName", "iOS");

// Build the session and the invoker the same way the other Appium drivers do
var session = options.ConvertToCapabilities().NewSessionModel();
var invoker = new WebDriverCommandInvoker(new Uri("http://127.0.0.1:4723/wd/hub"), TimeSpan.FromMinutes(1));

using var driver = new IosDriver(invoker, session);

// Members from the Appium base
var keyboardVisible = driver.IsOnScreenKeyboardVisible;
```
