# G4.WebDriver.Remote.Appium

## Description

`G4.WebDriver.Remote.Appium` is the shared base for mobile and device drivers that talk to an Appium server. It provides `AppiumDriverBase`, `AppiumOptionsBase` and `AppiumWebDriverServiceBase`, plus the `IGeolocation` and `IMobileDeviceKeyboard` capabilities (geolocation, hide keyboard, on-screen keyboard state). You normally install a concrete platform package, which pulls this one in.

## Installation

```bash
dotnet add package G4.WebDriver.Remote.Appium
```

Install `G4.WebDriver.Remote.Android`, `G4.WebDriver.Remote.Ios` or `G4.WebDriver.Remote.MacOs` for the platform you target. You also need a running Appium server.

## Getting started (C# example)

```csharp
using G4.WebDriver.Remote.Android;

// AndroidDriver inherits AppiumDriverBase, so the Appium members are available on it
var options = new AndroidOptions();
options.AddCapabilities("platformName", "Android");

using var driver = new AndroidDriver(new Uri("http://127.0.0.1:4723/wd/hub"), options);

// Members from the Appium base
var location = driver.GetGeolocation();
var keyboardVisible = driver.IsOnScreenKeyboardVisible;
driver.HideKeyboard();
```
