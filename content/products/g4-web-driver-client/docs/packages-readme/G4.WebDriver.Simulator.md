# G4.WebDriver.Simulator

## Description

`G4.WebDriver.Simulator` is a browser-less mock WebDriver for unit testing. `SimulatorDriver` returns simulated page sources, elements, navigation and JavaScript results without launching a real browser, so you can test automation flows quickly.

## Installation

```bash
dotnet add package G4.WebDriver.Simulator
```

## Getting started (C# example)

```csharp
using G4.WebDriver.Models;
using G4.WebDriver.Simulator;

// Create a simulator with default settings
using var driver = new SimulatorDriver();

// Navigate (no browser is started) and find a mock element
driver.Navigate().Open("https://example.com");
var element = driver.FindElement(By.CssSelector("div.mockClass"));
string html = driver.PageSource;

// Configure behavior through the session capabilities
var session = new SessionModel();
session.Capabilities.AlwaysMatch["ChildWindows"] = 1;
session.Capabilities.AlwaysMatch["ExceptionOnHandles"] = true;

using var configured = new SimulatorDriver(session);
```

## Configurable behaviors

| Capability | Effect |
| --- | --- |
| `ChildWindows` | Number of child windows to simulate. |
| `ExceptionOnHandles` | Throw an exception when `WindowHandles` is read. |
| `ThrowOnClose` | Throw an exception on `Close()` or `Quit()`. |
| `IsKeyboardShown` | Simulates on-screen keyboard visibility. |
