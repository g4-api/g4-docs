# G4.WebDriver.Remote.Opera

## Description

`G4.WebDriver.Remote.Opera` provides `OperaDriver`, `OperaOptions` and `OperaWebDriverService` for driving Opera browsers through `operadriver`. It builds on `G4.WebDriver.Remote.Chromium`.

## Installation

```bash
dotnet add package G4.WebDriver.Remote.Opera
```

You also need `operadriver`, or the address of a running WebDriver endpoint.

## Getting started (C# example)

```csharp
using G4.WebDriver.Models;
using G4.WebDriver.Remote;
using G4.WebDriver.Remote.Opera;

// Create the driver with options (starts operadriver)
var options = new OperaOptions();
options.Arguments = new[] { "--start-maximized" };

using var driver = new OperaDriver(options);

// Navigate and read an element
driver.Navigate().Open("https://example.com");
var heading = driver.FindElement(By.CssSelector("h1"));
Console.WriteLine(heading.Text);

// Cleanup
driver.Quit();

// Connect to an already running operadriver instead
// using var remote = new OperaDriver(new Uri("http://localhost:9515"), options);
```
