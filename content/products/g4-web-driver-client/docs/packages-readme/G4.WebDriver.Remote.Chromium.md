# G4.WebDriver.Remote.Chromium

## Description

`G4.WebDriver.Remote.Chromium` is the shared base for Chromium-based browsers. It provides `ChromiumDriverBase`, `ChromiumOptionsBase`, `ChromiumAndroidOptions` and the Chrome DevTools helpers that the Chrome, Edge and Opera packages inherit. You normally install a concrete browser package, which pulls this one in.

## Installation

```bash
dotnet add package G4.WebDriver.Remote.Chromium
```

Install `G4.WebDriver.Remote.Chrome`, `G4.WebDriver.Remote.Edge` or `G4.WebDriver.Remote.Opera` for a ready-to-use driver.

## Getting started (C# example)

```csharp
using G4.WebDriver.Remote.Chrome;

// ChromeOptions inherits ChromiumOptionsBase, so the shared options are available here
var options = new ChromeOptions();
options.Arguments = new[] { "--headless" };
options.BinaryLocation = @"C:\Program Files\Google\Chrome\Application\chrome.exe";

using var driver = new ChromeDriver(options);
driver.Navigate().Open("https://example.com");
driver.Quit();
```
