# G4.WebDriver.Remote.Edge

## Description

`G4.WebDriver.Remote.Edge` provides `EdgeDriver`, `EdgeOptions` and `EdgeWebDriverService` for driving Microsoft Edge (Chromium) through `msedgedriver`. `EdgeOptions.UseWebView` selects a WebView2 application on desktop.

## Installation

```bash
dotnet add package G4.WebDriver.Remote.Edge
```

You also need `msedgedriver`, or the address of a running WebDriver endpoint.

## Getting started (C# example)

```csharp
using G4.WebDriver.Models;
using G4.WebDriver.Remote;
using G4.WebDriver.Remote.Edge;

// Create the driver with options (starts msedgedriver)
var options = new EdgeOptions();
options.Arguments = new[] { "--inprivate" };

using var driver = new EdgeDriver(options);

// Navigate and read an element
driver.Navigate().Open("https://example.com");
var heading = driver.FindElement(By.CssSelector("h1"));
Console.WriteLine(heading.Text);

// Cleanup
driver.Quit();

// Connect to an already running msedgedriver instead
// using var remote = new EdgeDriver(new Uri("http://localhost:17556"), options);
```
